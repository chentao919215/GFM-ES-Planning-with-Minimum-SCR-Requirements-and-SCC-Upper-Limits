# GFM-ES 安全配置优化项目

本项目面向高比例 GFL-WG 接入场景下的 GFM-ES 配置优化问题，目标是在统一优化框架中协调系统运行经济性、短路电流安全性与电压支撑强度。项目关注同步机启停状态、GFL-WG 已接入状态以及 GFM-ES 投建决策之间的耦合关系，并通过 SCC-SCR 协同安全约束刻画不同设备在故障电流贡献和系统强度支撑方面的差异化作用。

## 最终目标

本科研项目的最终目标是建立一套面向不确定新能源接入场景的 GFM-ES 配置优化方法，主要包括：

1. 构建计及 UC 与 GFM-ES 投建决策的 SCC-SCR 协同安全约束配置框架，在同一优化模型中同时嵌入短路电流水平约束与电压支撑强度约束，实现经济性、安全性和系统强度之间的协调权衡。
2. 建立 GFL-WG 与 GFM-ES 在正常工况和故障工况下的等值模型，形成可嵌入优化模型的线性安全约束表达，为 SCC 与 SCR 协同约束提供可求解的数学建模基础。
3. 面向 GFL-WG 出力分布不确定且精确概率分布难以获取的情况，进一步构建分布鲁棒 GFM-ES 配置模型，用于优化 GFM-ES 的选址、定容与运行策略，提升配置方案在高比例 GFL-WG 场景下的安全性与鲁棒性。

## 当前进度

当前代码已完成确定性、单时刻的 IEEE-30 节点 GFM-ES 配置优化原型，主要进展如下：

- 已搭建主脚本 `code/scripts/run_single_snapshot_planning.m`，能够完成参数加载、网络构建、优化求解、结果打包、结果保存与摘要输出。
- 已实现已知 GFL 接入节点和候选 GFM-ES 节点下的规划模型，支持同步机启停、GFM-ES 投建、节点功率平衡、线路潮流和机组出力约束。
- 已将经典 SCR 下限约束和短路电流水平约束嵌入优化模型，用于刻画 GFL 节点的系统强度需求和故障电流安全边界。
- 已通过阻抗矩阵重构与线性化约束，将安全约束转化为可由 YALMIP 与 Gurobi 求解的混合整数优化模型。
- 已对核心函数进行精简和性能优化，主脚本运行时间已由约 1680 s 降至约 131 s，当前版本以“维持主脚本可跑通、减少冗余功能”为整理原则。

## 项目结构

```text
code/
  scripts/        主运行脚本
  functions/      数据加载、网络构建、优化建模、安全约束与结果输出函数
data/
  params/         默认算例参数及参数生成脚本
docs/             项目说明与环境记录
results/          优化运行结果输出目录
```

当前仓库对应的是完整研究框架中的确定性单时刻建模与求解阶段；后续工作可在此基础上继续扩展多时段 UC、GFL-WG 不确定性建模以及分布鲁棒 GFM-ES 配置模型。
