# 基于场景随机优化的多时段模块化 GFM-ES 配置优化模型参数审计报告

## 1. 审计范围、分类与追踪方法

本轮审计以当前默认主入口 `code/scripts/system/run_multiple_snapshot_planning.m` 及其实际调用链为唯一生效基准。当前参数链为：

`generate_multiple_snapshot_default_params.m` → `multiple_snapshot_default_params.json` → `load_multiple_snapshot_case.m` → `normalize_multiple_snapshot_conf.m` → 网络、UC、GFM-ES、LVRT、SCC/SCR、目标函数与结果打包模块。

审计采用静态代码追踪，并对现有 JSON 做只读解析和独立数值复核；未运行 MATLAB 参数生成脚本、参数加载函数或任何优化求解流程。原因是默认参数生成脚本会覆盖 JSON，不符合本轮“不生成或覆盖算例数据”的约束。未调用 YALMIP、Gurobi、主优化流程，也未写入 `results/`、`data/` 或源代码目录。

Excel 台账共记录 74 个唯一参数对象，按以下五类编号：

- `SYS-*`：IEEE-30 系统基础参数；
- `UC-*`：同步机与 UC 参数；
- `GFM-*`：GFM-ES 规划、储能、经济与正常运行参数；
- `GFL-*`：GFL-WG、典型日和随机场景参数；
- `SEC-*`：同步机/GFM/GFL 故障参数、LVRT、SCC 与 SCR 安全参数。

同一物理参数的原始值、换算值和标幺值共用一个编号；具有独立物理、经济或安全含义并单独进入约束或结果解释的派生量才另行编号。McCormick 上下界、Big-M、阻抗重构容差、分段精度、目标缩放和求解器设置未纳入台账。

`code/scripts/equipment/` 下的 GFM/GFL/同步机 Simulink 参数脚本不在当前优化主入口调用链内，属于设备级仿真或备用流程，未与当前生效优化参数混合统计。后台入口 `start_multiple_snapshot_planning_longrun.m` 最终仍调用同一主脚本，不形成另一套物理参数。

## 2. 参数来源与单位口径总体情况

当前系统网络的原始数据来自运行环境中的 MATPOWER `case30`，再整体写入 JSON；风电和负荷基础轨迹来自 MOST 示例 `ex_wind_profile_d`、`ex_load_profile` 和 `ex_case3b`。仓库没有保存 MATPOWER/MOST 版本、源文件哈希或生成环境快照，因此当前 JSON 能作为现有数值快照，但不能单独证明未来重新生成时完全一致，涉及 `SYS-001`、`SYS-005`、`GFL-003`。

当前系统标幺基准为 100 MVA、135 kV，派生基准电流 0.4276668661 kA、基准阻抗 182.25 Ω；基准公式和现有 case30 数据内部一致，涉及 `SYS-001`～`SYS-004`。30 个节点的 `BASE_KV` 当前均为 135 kV，因此本算例没有多电压等级换算冲突；但实现隐含单一电压基准。

MATPOWER 中实际进入模型的主要列为：有功负荷、节点类型中的参考节点、机组接入节点与 `PMAX`、支路端点与 `BR_R/BR_X/BR_B/RATE_A`、发电成本二次系数，涉及 `SYS-005`、`SYS-007`、`SYS-009`、`SYS-010`、`SYS-013`～`SYS-017`、`SYS-021`。无功负荷、稳态电压限值、多数机组列、发电机/支路状态、变比、相移、`RATE_B/C` 和相角差限值未进入当前优化，涉及 `SYS-006`、`SYS-008`、`SYS-011`、`SYS-012`、`SYS-018`～`SYS-020`、`SYS-022`。

人为设定参数普遍有清晰的代码字段和可用数值，但多数缺少文献、工程数据、价格基年或标准依据。派生参数的公式、维度和单位传递总体可追踪；主要剩余风险集中在容量 MVA/MW 口径、启停事件成本、设备标幺基准以及 GFM 投资年化来源。

当前主脚本会在每次运行时先执行参数生成脚本并覆盖 JSON。因此，JSON 不是独立可维护输入，直接修改其中对应 `SYS-001`、`SYS-002`、`SYS-005`～`SYS-022`、`UC-001`～`UC-006`、`GFM-001`～`GFM-007`、`GFM-009`～`GFM-012`、`GFM-015`、`GFL-001`～`GFL-010`、`GFL-012`、`SEC-001`～`SEC-013` 的值不会最终生效。当前未发现面向物理、经济、运行、场景或安全参数的默认值回退路径。

## 3. 优先核查参数

本轮识别 10 个高优先级参数，和 Excel 的 `02_优先核查参数` 完全一致：

1. `SYS-015`：线路电抗统一乘 1.75，同时影响 DC 潮流与 SCC/SCR 导纳网络，但无来源说明。
2. `SYS-017`：MATPOWER `RATE_A` 原义为 MVA，当前按双向有功 MW 限额使用，存在直接量纲解释风险。
3. `UC-004`：当前生效值为 1 个时段（2 h），README 仍写 3 个时段（6 h）；1 个时段也几乎不形成额外最小持续时间限制。
4. `UC-005`：5% `Pmax` 处的小时运行成本率数值被直接当作单次启动成本，且 README 的倍率已经过期。
5. `UC-007`：没有外部初始开机状态和已持续开停机时间；状态、爬坡和最小开停机均采用典型日首尾循环。
6. `GFM-014`：寿命、贴现率、资本回收因子、残值和更换周期均未定义，无法验证年化成本来源。
7. `GFL-003`：风电轨迹来自外部 MOST 示例，经倒序、典型日倍率和场景倍率生成，缺少版本与统计依据。
8. `SEC-001`：6 台机组统一采用 0.04 p.u. 次暂态/故障等效电抗，缺少机组级数据来源。
9. `SEC-011`：12.25 kA 的统一短路电流上限直接决定 SCC 可行域，缺少设备遮断能力或规范依据。
10. `SEC-012`：经典 SCR 下限 3 直接决定电压支撑可行域，缺少并网标准或文献依据。

## 4. 量纲、标幺基准与年化口径风险

### 4.1 量纲风险

- `SYS-017` 将 `RATE_A` 的 MVA 额定值直接作为 MW 有功限额；当前 DC 近似可使用该处理，但必须明确这是 `|P|≤RATE_A` 近似，而非交流视在功率约束。
- `UC-005`、`UC-006` 将发电成本函数在 5% 负载处的数值当作每次启停成本。若 MATPOWER 成本函数解释为货币/小时，当前缺少从成本率到事件成本的时间或经验系数。
- `GFM-006`、`GFL-002`、`SEC-003`、`SEC-007`、`SEC-010`、`SEC-016` 在额定电流、故障电流和 SCR 换算中以 MW 作为设备容量基准，隐含额定功率因数为 1、MW≈MVA。
- `GFM-011`～`GFM-013`、`GFL-012` 和 `SYS-021` 未注明货币和价格基年；尽管数学单位传递可闭合，不同成本项能否直接相加仍需确认。

### 4.2 标幺基准风险

- `GFM-015` 把设备基准 0.04 p.u. 乘 `100/30` 换算为系统基准 0.133333 p.u.；`SEC-004` 同样按 30 MW 模块基准换算虚拟电抗。公式一致，但设备基准容量需确认是 30 MVA 还是 30 MW。
- `SEC-001` 当前无需从机组基准换算，因为 case30 中 6 台机组 `MBASE` 均为 100 MVA，与 `SYS-001` 相同；但统一 0.04 p.u. 的物理来源仍未确认。
- `SEC-010` 的 1.05 倍额定增量电流换算为 0.63 系统 p.u.，`SEC-003` 的 GFM 故障电流换算为 0.9 系统 p.u.；两者的数值链一致，容量基准假设需在论文说明。

### 4.3 年化口径风险

- `GFM-011`、`GFM-012` 被直接视为年化单位成本，并由 `GFM-013` 汇总为每模块 2,515,200/年；代码没有使用 `GFM-014` 所代表的寿命、贴现率或 CRF。
- `GFL-008` 与 `GFL-009` 生成 `GFL-011`，总运行权重为 8760 h；运行成本和弃风成本再乘 `GFL-004` 的场景概率。该年化链内部一致。
- `UC-005`、`UC-006` 的启停动作跨风场景共享，只乘典型日代表天数，不乘场景概率或时段持续时间；这是事件成本口径，前提是单次成本单位本身成立。
- `SYS-021`、`GFL-012` 与 GFM 年化投资成本合计到同一年度目标，必须统一货币和价格基年。

## 5. 人为设定但缺少注释或来源说明的参数

下列参数已在代码中明确赋值，但缺少足以支撑论文算例的来源：

- 线路修正：`SYS-014`～`SYS-016`；
- 同步机运行与启停：`UC-001`～`UC-006`；
- GFM 候选位置、模块上限、额定功率/能量、效率、SOC、成本和正常电抗：`GFM-001`～`GFM-004`、`GFM-006`、`GFM-007`、`GFM-009`～`GFM-012`、`GFM-015`；
- GFL 接入、容量、场景概率/倍率、典型日权重/倍率及弃风成本：`GFL-001`～`GFL-004`、`GFL-006`～`GFL-010`、`GFL-012`；
- 同步机/GFM/GFL 故障与安全阈值：`SEC-001`、`SEC-002`、`SEC-006`～`SEC-013`。

建议优先补充来源；无法获得直接文献或工程数据的参数，应在论文中明确标注为算例假设，并安排灵敏度分析。

## 6. 论文算例部分需要明确说明的参数

Excel 的 `04_论文参数清单` 已列出 67 项。论文至少应覆盖：

- 系统与网络：`SYS-001`～`SYS-003`、`SYS-005`、`SYS-007`、`SYS-009`、`SYS-010`、`SYS-012`～`SYS-018`、`SYS-021`；
- 同步机与 UC：`UC-001`～`UC-008`，特别是日内循环边界和跨场景共享决策；
- GFM-ES：`GFM-001`～`GFM-015`，特别是候选集、模块数量上限、2 h 额定时长、SOC 日内闭环和投资年化口径；
- GFL-WG 与随机场景：`GFL-001`～`GFL-012`，包括基础轨迹来源、典型日权重、场景概率和倍率；
- SCC/SCR：`SEC-001`～`SEC-016`，包括设备基准、LVRT 三段参数、12.25 kA 上限、SCR 下限 3、源在线规则、安全节点集合、日内并集/交集聚合和 SCR 额定容量基准。

论文应把 `GFL-003` 的可用出力与实际出力、弃风功率严格区分；高风场景的可用出力最高 87.12 MW，可超过 `GFL-002` 的 60 MW 额定容量，模型会通过弃风下界把实际出力限制在额定容量内。

## 7. 重复定义、覆盖、未使用与模块口径不一致

### 7.1 重复定义与文档漂移

- `UC-004`：参数源和 JSON 为 1 个时段，README 第 144 行仍写 3 个时段。
- `UC-005`、`UC-006`：参数源按 1.0/0.25 倍 5% 负载参考成本生成，README 第 145 行仍写 2cG/0.5cG。

这些 README 表述不进入主调用链，因此当前最终生效值以参数源和 JSON 为准；但文档漂移会直接影响论文和结果复核。

### 7.2 参数覆盖

默认主脚本第 8 行会重生成 JSON。因此，对 Excel `03_风险汇总`“参数覆盖”行列出的参数，维护优先级明确为：参数源 `.m` 高于生成后的 JSON。当前调用链未发现第二套物理参数配置或静默默认值回退。

### 7.3 定义但未使用

- `SYS-004` 仅生成、加载和公开保存，当前优化不读取；
- `SYS-006`、`SYS-008`、`SYS-011` 不进入当前 DC 有功优化；
- `SYS-012`、`SYS-018` 的发电机/支路状态被忽略，当前因全为 1 暂无数值差异，但换算例时风险较高；
- `SYS-019`、`SYS-020`、`SYS-022` 当前数据恰好符合模型假设，但字段本身未被使用或校验；
- `GFM-008` 仅作为额定时长解释量保存，约束直接使用功率和能量；
- `GFL-013` 仅用于确定性退化诊断，不进入目标或约束。

### 7.4 不同模块口径不一致

- `UC-001` 使用 20% `Pmax` 作为有效最小出力，`UC-002` 却在 5% `Pmax` 处计算启停成本参考值；该参考点低于允许的开机出力区间。
- `SYS-017` 在 MATPOWER 数据层是 MVA，在优化约束层按 MW 使用。
- `GFM-006`、`GFL-002` 和 `SEC-016` 以 MW 额定容量换算电流和 SCR，需明确额定功率因数假设。
- `UC-004`～`UC-006` 的代码/JSON口径与 README 不一致。

## 8. 当前无法从代码和数据文件确认的参数

- MATPOWER `case30` 和 MOST 示例数据的精确版本、源文件哈希及重新生成环境无法确认，涉及 `SYS-001`、`SYS-005`、`GFL-003`。
- 发电成本、启停成本、弃风成本及 GFM 年化成本的货币、价格基年和引用来源无法确认，涉及 `SYS-021`、`UC-005`、`UC-006`、`GFM-011`～`GFM-014`、`GFL-012`。
- 同步机显式初始状态、初始已开/停持续时间不存在，当前只有硬编码循环规则，涉及 `UC-007`。
- 线路修正系数、GFM/GFL额定与故障能力、LVRT阈值、SCC上限和SCR下限的工程或规范依据无法确认，涉及 `SYS-014`～`SYS-016`、`GFM-006`、`GFM-007`、`GFM-015`、`GFL-002`、`SEC-001`、`SEC-002`、`SEC-006`～`SEC-012`。
- `GFM-014` 明确缺失，不存在可追踪的寿命、贴现率或 CRF 默认回退。

## 9. 总体结论

当前默认主调用链的参数组织较集中：参数源、JSON、公开分组CONF、内部扁平CONF和最终约束之间总体可追踪。基准电流、基准阻抗、逐时负荷、风场景、运行权重、GFM模块年成本、GFM阻抗/故障电流和LVRT阈值等派生量的公式与当前 JSON 数值一致；未发现当前生效物理参数被静默默认值替代。

本轮最主要的问题不是派生公式的数值不一致，而是参数来源、单位解释、年化依据和文档同步：`SYS-015`、`SYS-017`、`UC-004`、`UC-005`、`UC-007`、`GFM-014`、`GFL-003`、`SEC-001`、`SEC-011`、`SEC-012` 应在论文定稿前优先处理。其次应修正 README 与当前参数源的 UC 口径漂移，并把 MATPOWER/MOST 版本和参数生成环境纳入可复现记录。

本报告只审计参数来源、数据流、单位和最终生效口径，不评价模型公式本身是否正确，也未修改任何参数、源代码、配置、数据、约束或求解逻辑。
